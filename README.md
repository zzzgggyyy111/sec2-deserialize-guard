会话恢复接口直接读客户端递交的序列化数据，有人构造了一个对象，服务器上就执行了命令：这不是单个解析函数的输入校验问题，而是整条还原链路缺少边界。解析只产出中间表示，不做类型还原；还原只能接受白名单内的类型；任何类引用与可调用对象都必须拒绝；嵌套深度与元素数量必须有上限；循环引用必须拒绝；反序列化失败必须整体回滚，不得返回部分结果；还原结果必须再做一次类型校验；批量解析中每条输入相互独立。不变量：任何输入都无法触发代码执行，同一输入两次解析结果相同。
